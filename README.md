# hyprland-dms-config

My [Hyprland](https://hypr.land) + DMS (DankMaterialShell) config on Nobara (Fedora 44),
to be adapted for left-handed use like my niri setup
([niri-dms-config](https://github.com/mirko-geno/niri-dms-config)).

## Contents

```
backup.sh           # saves the current system config into this folder
restore.sh          # installs what is missing (Hyprland, DMS, ...) and puts the config back
hypr/
├── hyprland.lua    # main Hyprland config (Lua, Hyprland 0.57+)
├── stack.lua       # custom "stack" layout + its binds (Super+Alt+T / Super+Alt+Space)
├── workspaces.lua  # workspaces 1-4 on the landscape monitor, 5-8 on the portrait one
└── dms/            # Hyprland files generated by DMS, loaded with require() at the end of hyprland.lua
dms/
├── config/         # ~/.config/dms: settings.json, monitors.json, themes, Firefox/Zen css
└── state/          # ~/.local/state/dms/session.json: current wallpaper, monitor profile
alacritty/
├── alacritty.toml  # terminal config
└── dank-theme.toml # colors generated by DMS
fish/               # ~/.config/fish: config.fish, prompt, theme, key bindings, universal variables
cursor/
├── Hacked-Red/     # ~/.icons/Hacked-Red: the cursor theme
├── index.theme     # ~/.icons/default/index.theme: fallback cursor theme
└── 90-cursor.conf  # ~/.config/environment.d: XCURSOR_THEME and XCURSOR_SIZE
icons/              # ~/.icons: Sweet-Red icon theme (set in DMS) + candy-icons (its base)
ssh-agent/
└── 90-ssh-agent.conf # ~/.config/environment.d: SSH_AUTH_SOCK for gcr-ssh-agent
claude/
├── *.jsonl         # Claude Code session(s) used to build this setup
└── memory/         # Claude Code memory for this project
wallpaper/          # the wallpaper currently in use
```

## Backup and restore

```sh
# Save the current state (after changing something in Hyprland or DMS)
./backup.sh

# Restore the saved config
./restore.sh
dms restart
```

- `backup.sh` replaces whatever is in this folder with the current system config.
  Only `*.lua` files are copied from `~/.config/hypr` (leftovers like `hyprland.lua.orig`
  are skipped).
- `restore.sh`:
  1. Installs the missing packages (see [Fresh install](#fresh-install)).
  2. Checks that the saved config is valid with `Hyprland --verify-config`
     (this also checks the files in `hypr/dms/`).
  3. Backs up your current system config to `~/.config-backups/<date>/`.
  4. Copies everything, installs `fish`/`zoxide` if missing and makes fish the default shell.
- Hyprland reloads its config on save (or `hyprctl reload`); DMS needs `dms restart`.
- Only the wallpaper in use is saved, not the whole `~/.wallpapers` folder. On restore,
  it is copied to its original path if it is missing.

> **Shared with niri:** `dms/`, `alacritty/`, `fish/`, `cursor/`, `ssh-agent/` and the
> wallpaper are the same files the niri repo saves, since both sessions use them.
> Restoring one repo overwrites them with that repo's version.

## Fresh install

On a fresh **Fedora Workstation** (it already has GDM), log in to GNOME, clone the repo and run:

```sh
git clone git@github.com:mirko-geno/hyprland-dms-config.git ~/hyprland-dms-config
cd ~/hyprland-dms-config
./restore.sh   # asks for sudo (packages) and your password (chsh to fish)
```

Then log out and pick **Hyprland** in GDM (gear icon at the bottom right).

`restore.sh` installs only the packages that are missing, so on a system that is already
set up it does not ask for sudo:

| Source | Packages |
|---|---|
| [`avengemedia/dms`](https://copr.fedorainfracloud.org/coprs/avengemedia/dms/) COPR (+ its dependency repo `avengemedia/danklinux`) | `dms` (pulls `dms-cli`, `quickshell`), `danksearch`, `matugen`, `dgop` |
| [`lionheartp/Hyprland`](https://copr.fedorainfracloud.org/coprs/lionheartp/Hyprland/) COPR (recommended by the Hyprland wiki) | `hyprland`, `xdg-desktop-portal-hyprland` |
| Fedora | `alacritty`, `fish`, `zoxide`, `gcr`, `gnome-keyring`, `breeze-icon-theme`, `xdg-desktop-portal-gtk` (and `dnf5-plugins` for `dnf copr`) |

- DMS packages are installed with weak deps (DMS recommends `cava`, `qt6ct`,
  `qt6-qtmultimedia`...). Hyprland is installed without them: they would pull `nwg-panel`,
  `wofi` and `kitty`, which DMS already covers.
- The Hyprland COPR also ships `quickshell` and `matugen`; they are excluded from it
  (`excludepkgs`) so the versions DMS depends on are kept.
- DMS runs as the `dms.service` systemd user service; `restore.sh` adds it to
  `hyprland-session.target` (what `dms setup` does), so it starts with the Hyprland session.
- Run it from a graphical session (it uses `systemctl --user`).

Manual equivalent of the package part:

```sh
sudo dnf copr enable avengemedia/dms
sudo dnf copr enable lionheartp/Hyprland
sudo dnf config-manager setopt "copr:copr.fedorainfracloud.org:lionheartp:Hyprland.excludepkgs=quickshell,matugen"
sudo dnf install dms danksearch matugen dgop alacritty fish zoxide gcr gnome-keyring breeze-icon-theme xdg-desktop-portal-gtk
sudo dnf install --setopt=install_weak_deps=False hyprland xdg-desktop-portal-hyprland
systemctl --user add-wants hyprland-session.target dms.service
```

## How DMS is started

`hyprland.lua` (generated with `dms setup headless --compositor hyprland`) starts
`hyprland-session.target` on launch, which pulls in `graphical-session.target` and with it
the `dms.service` systemd user service, the same way the niri session does.

## Changes from the DMS-generated config

- `kb_layout = "latam"` in `hyprland.lua`: unlike niri, Hyprland does not read the system
  keyboard layout (`localectl`), and an empty value falls back to `us`.

## Other keybind changes

In `hypr/dms/binds-user.lua` (the DMS file for user binds; the DMS keybind editor keeps
only its `hl.bind` / `hl.unbind` lines):

- `Alt + F4` closes the focused window; the stock `Super + Q` is removed.
- `Super + V` toggles floating; the stock `Super + Shift + T` is removed. `Super + V` was
  the DMS clipboard history, which moved to `Super + C`.
- Left-handed focus, like the niri setup: `Super + 1 / 2 / 3 / 4` = left / right / up / down.
  The stock `Super + H J K L` are removed; `Super + arrows` are kept.
- `Super + 5…9` removed (workspaces are switched only with F keys, see [Workspaces](#workspaces)).

## DMS bar

Two bars in `dms/config/settings.json` (`barConfigs`), each tied to screens by name:

| Bar | Screens | Difference |
|---|---|---|
| Main Bar | the portrait monitor (`HDMI-A-1`) | no battery widget |
| Laptop Bar | `eDP-1`, `eDP-2` (a laptop's built-in panel uses one of those names) | same widgets + battery |

DMS matches plain strings against the output name, so the Laptop Bar only appears on a
machine with a built-in screen. The battery widget lives only there because on a machine
without a battery DMS still shows it, as a generic icon.

The Laptop Bar is a copy of the Main Bar: a widget change made in DMS settings to one bar
is not applied to the other.

## Stack layout

`hypr/stack.lua` registers a custom Lua layout (`lua:stack`), used on every workspace.
It is loaded last from `hyprland.lua`, so its binds replace the DMS stock ones.

A workspace is a row of equal **cells** along the long side of the monitor: columns on
landscape monitors, rows on portrait ones. Each cell is tiled like dwindle.

| Shortcut | What it does |
|---|---|
| `Super + T`, `Super + Space` (and any app opened another way) | Normal: splits the focused window in half, side by side if it is wider than tall, top/bottom otherwise (direction kept afterwards, like `preserve_split`) |
| `Super + Alt + T` | Opens a terminal as a new cell: 100% → 50/50 → 33/33/33… |
| `Super + Alt + Space` | Same, for the app picked in Spotlight (the next window that opens) |
| `Super + Ctrl + 1 / 2 / 3 / 4` (or `Super + Shift + arrows`) | Swaps the focused window with its neighbor left / right / up / down (left-handed, like niri; the stock `Super + Shift + H J K L` are removed) |
| `Super + R` | Toggles the focused window's split between side by side and top/bottom |
| `Super + 1 / 2 / 3 / 4` (or `Super + arrows`) | Focus left / right / up / down (generic Hyprland, set in `binds-user.lua`) |

- Closing (or floating, or moving away) a window gives its space back: its split partner
  takes the whole space, an empty cell disappears and the cells are re-split equally.
- When stacking, normal windows already split in the stack direction (top/bottom on
  portrait, side by side on landscape) become cells of their own first. Example on the
  portrait monitor: two normal windows one above the other, then `Super + Alt + T` →
  33/33/33 (not 25/25/50). Splits in the other direction stay as one cell: a normal
  window with two side-by-side windows below it, then `Super + Alt + T` → three equal
  rows, the middle one shared by the two side-by-side windows.
- Generic `window.move` / `window.swap` don't reach Lua layouts, so moving goes through the
  layout message `move l|r|u|d` (`hl.dsp.layout("move l")`). Ties between equally close
  windows go to the most aligned one, then the most recently focused.
- Not supported (yet): resizing (all splits are 50/50 and cells are equal), the stock
  `Super + [` / `Super + ]` preselect binds.
- The layout state lives in Lua: a config reload (e.g. saving any file in `~/.config/hypr`)
  re-tiles the existing windows as normal splits.
- If `Super + Alt + Space` is used and Spotlight is closed without opening anything, the
  next window opened later still goes to a new cell.

## Workspaces

`hypr/workspaces.lua` pins workspaces to monitors with workspace rules, following the
keyboard's F-key groups (F1–F4, gap, F5–F8):

| Shortcut | What it does |
|---|---|
| `Super + F1` … `Super + F4` | Workspaces 1–4, always on the landscape monitor (DP-1) |
| `Super + F5` … `Super + F8` | Workspaces 5–8, always on the portrait monitor (HDMI-A-1) |
| `Super + Ctrl + F1` … `F8` | Send the focused window to that workspace |

- Each monitor starts on its first workspace (1 and 5).
- Going to a workspace on the other monitor moves the focus (and the cursor) there.
- The DMS stock `Super + 1…9` binds are removed (in `hypr/dms/binds-user.lua`): workspaces
  are switched only with the F keys. `Super + Shift + 1…9` (send window) still exists;
  numbers are global, so `Super + Shift + 5` sends to workspace 5 on the portrait monitor.
- Workspaces are created when visited and removed when empty and not shown.
- The monitor names are hard-coded: on another machine, update them in `workspaces.lua`.

## Cursor

Apps not started by the compositor fall back to the `default` cursor theme, which is
Adwaita, unless these two files are in place:

- `~/.icons/default/index.theme` makes `Hacked-Red` the fallback theme.
- `~/.config/environment.d/90-cursor.conf` sets the theme and size for the whole session
  (applied on the next login).

## SSH agent

Uses `gcr-ssh-agent` (from GNOME's `gcr`, works without the GNOME session): the SSH key
passphrase is asked once per session in a popup.

- `systemctl --user enable --now gcr-ssh-agent.socket` (done by `restore.sh`).
- `~/.config/environment.d/90-ssh-agent.conf` sets `SSH_AUTH_SOCK=${XDG_RUNTIME_DIR}/gcr/ssh`.

## Claude Code session

`claude/` holds the Claude Code session where this setup was built, plus its memory.
`restore.sh` puts them back in `~/.claude/projects/<repo path with "-">/`, so the
session can be resumed from the repo folder:

```sh
cd ~/hyprland-dms-config
claude --resume b72d4f5c-b8ea-4bf6-810c-f3d731982a15
```

The session includes command outputs from this machine (paths, packages, email),
so the repo should stay private.
